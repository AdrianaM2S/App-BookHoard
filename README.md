## Descripción del problema 
El problema que BookHoard ofrece resolver para el cliente es poder catalogar los libros que tenga en su posesión y cuales hayan leído, están en proceso de leer o no han empezado de leer. Para personas que tiene muchos libros se le puede hacer difícil acordarse cuales tiene, esto puede terminar en el lector comprando el mismo libro dos veces o en situaciones donde el libro es de una serie se puede terminar comprando el libro equivocado pensando que tenía él que venía antes. También es difícil acordarse que libros ya terminaron de leer y cuales no han empezado, BookHoard permite que el usuario marque libros como leídos, leyendo o no leídos.

## Objetivo del sistema 
Nuestro objetivo con este website es ofrecer un método para categorizar libros de una manera organizada y personal. El usuario puede crear “shelfs” para organizar los libros que tenga y puede marcar esos libros como leídos, leyendo o no leídos. Si el libro no está en el sistema el usuario también tiene la habilidad de registrar ese libro al sistema con solo llenar la información del libro.

##  Público objetivo
El público objetivo para BookHoard son los lectores y fans de la literatura. Esas personas que les interesa leer libros y descubrir más libros para leer y quieren tener un sitio donde pueden tener un catalogo de libros que han leido o que quieren leer.
